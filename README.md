## 🚀 **Getting Started**

### **Prerequisites**
- Node.js 18+ 
- npm or yarn
- Stellar wallet (Freighter, xBull, or Albedo)

### **Installation**

```bash
# Clone the repository
git clone https://github.com/AmaanSayyad/AssetNest.git
cd AssetNest

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

### **Environment Setup**

```bash
# Copy environment variables
cp .env.example .env

# Configure your Soroban network settings
SOROBAN_NETWORK=TESTNET
SOROBAN_RPC_URL=https://soroban-testnet.stellar.org
```
